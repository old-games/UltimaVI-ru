# Редактор сохранений для проверки перевода

Страница правит сохранение Ultima VI (`SAVEGAME/OBJLIST`): переносит отряд к любому NPC или по координатам,
меняет время, карму и флаги разговора. Нужна, чтобы быстро добраться до нужного диалога.

## Как пользоваться

1. В игре сохранись и выйди из `GAME.EXE` (DOSBox можно не закрывать).
2. Открой `index.html` в браузере.
3. Chrome, Edge, Яндекс.Браузер: «Открыть папку игры» → выбери каталог игры (или `SAVEGAME`). Страница сама
   прочитает и запишет файлы, перед первой записью каждого сделает копию `*.BAK`; «Вернуть из копий» откатывает всё.
   Firefox, Safari: «Открыть папку игры» тоже выбирает папку, но только для чтения. Изменения скачиваются архивом
   «Скачать изменённые файлы (SAVEGAME.zip)» — распакуй его в `SAVEGAME` с заменой файлов. Копий `*.BAK` тут нет:
   перед первой правкой скопируй `SAVEGAME` вручную.
   Можно открыть и один файл `OBJLIST` («или файл»), но тогда вещи отряда при телепорте не переносятся и выдача
   предметов недоступна (см. ниже).
4. Найди NPC, нажми «Телепорт» → «Сохранить». Запусти `GAME.EXE`.

Вещи персонажа игра хранит в файле участка карты, где он стоит (`SAVEGAME/OBJBLKxx`), и загружает только участки
рядом с отрядом. Поэтому при телепорте страница переносит инвентарь отряда в файл нового участка — для этого нужна
открытая папка, а не один файл.

NPC ходят по расписанию: если персонаж ушёл или спит, поменяй время. Если отряд оказался в стене, перенеси его
с другой стороны.

## Карта

Внизу страницы — карта мира и подземелий (4 пикселя на клетку, масштаб 1–8). Красное — отряд, синие точки — NPC
(клик — телепорт к нему), жёлтое — выбранный в списке NPC. Клик по карте выбирает клетку и заполняет «Телепорт по
координатам»; «Перенести отряд сюда» — телепорт. Ещё можно ввести пиксели с карт Ian Albert (16384×16384 и
4096×4096, как и `maps/` репозитория — 16 пикселей на клетку): страница поделит их на 16.

Картинки карт (`web/save/maps/`) в git не хранятся: их делает `tools/web_npc.py` из `maps/LZMAP.*.png` — workflow
Pages при публикации, локально — `../.venv/bin/python -m tools.web_npc` (нужен Pillow).

## Яйца и монстры

Монстров игра выпускает из «яиц» — невидимых объектов на карте. Флажок «яйца монстров» показывает их на карте
(зелёные квадраты; наведи — кто в яйце, шанс, днём/ночью, отношение к отряду), список рядом оставляет только яйца с
нужным монстром и считает их по этажам. Без открытой папки — яйца новой игры (`unpacked/LZOBJBLK`, `LZDNGBLK`),
с папкой — из файлов сохранения. Яйцо срабатывает, когда отряд оказывается дальше 8 и ближе 20 клеток от него
(сразу после загрузки или при подходе), поэтому отряд стоит переносить клеток за 10–15 от яйца. Проверено на стенде.

«Создать монстров» кладёт своё яйцо (шанс 100%, ровно столько монстров, сколько указано) в выбранную клетку;
«Клетка в 10 к югу от отряда» выбирает место, где яйцо сработает сразу. Отношение к отряду и режим поведения —
как чаще всего у этого монстра в яйцах игры (отношение можно поменять). «Убрать яйца в клетке» удаляет яйца вместе
с содержимым. Нужна открытая папка игры.

## Предметы

«Выдать предметы»: член отряда, предмет из списка с иконками (поиск по названию или номеру), количество. Стопки (золото, реагенты,
стрелы) складываются, до 65535; остальное — по штуке. Быстрые кнопки: золото, все реагенты, книга со всеми
заклинаниями (выдаётся в руку — иначе игра не даёт колдовать; так можно проверить названия заклинаний в книге).
Варианты предмета (цвет зелья, горящий факел, состояние сундука) — отдельные строки списка. Поле «качество»:
у книги и свитка это номер текста из `book.json` (под полем — список текстов, книгу можно прочитать в игре), у ключа —
номер замка (под полем — двери и сундуки с замками на участке получателя). Названия предметов — из `look.json`,
заклинаний — из перевода `GAME.EXE`. Нужна открытая папка игры.

## Уровень и характеристики

«Уровень и характеристики»: член отряда, уровень, опыт, здоровье, мана, сила, ловкость, интеллект. Круг заклинаний,
которые персонаж может колдовать, не выше его уровня. В игре уровень поднимает святыня (на 1 за посещение, если
опыта не меньше 100, 200, 400 … 6400 для уровней 2–8, и +3 к характеристике святыни) — можно просто дать опыта и
сходить в святыню. «Поставить уровень» меняет уровень сразу, поднимает опыт до нужного и восстанавливает здоровье
(максимум здоровья — уровень × 30); «Применить» записывает поля как есть. Работает и с одним файлом `OBJLIST`.

## Файлы

- `objlist.js` — формат `OBJLIST` (смещения сверены с движком Nuvie из ScummVM) и операции над ним.
- `objblk.js` — файлы предметов `OBJBLKxx`: перенос инвентаря отряда, выдача предметов и заклинаний, яйца монстров.
- `zip.js` — архив без сжатия для Firefox и Safari.
- `npc.js` — имена NPC, места использования флагов разговора, предметы и заклинания; генерируется
  (из `conversations/`, `look.json`, `BASETILE`, `TILEFLAG`, `GAME.EXE`, перевода), вместе с атласом иконок
  `items.png` (из `tiles/`, нужен Pillow):
  `python3 -m tools.web_npc`. После правки скриптов его стоит перегенерировать.
- `app.js`, `index.html` — интерфейс.
- `maps/` — карты для страницы (генерируются, не в git).
- `test.js` — тест `objlist.js`, `objblk.js` и `zip.js`: `node web/save/test.js` (запускается в CI).
