Кому:

Стопки (золото, реагенты, стрелы) складываются с уже имеющимися; остальные предметы — по одному на каждую единицу количества. Качество: у книги и свитка — какой текст в нём (книгу можно прочитать в игре), у ключа — какой замок он открывает. Книга выдаётся в руку: колдовать можно только с ней. Работает только с открытой папкой игры.
