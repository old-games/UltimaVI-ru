## Время суток в диалогах: $T и $V

`$T` — время суток в первой форме, `$V` — во второй. Обе формы задаются в `patches/translation.json`
у строк `morning`, `afternoon`, `evening` через `|`: `"утра|утром"`, `"дня|днём"`, `"вечера|вечером"` —
тогда «Доброго $T» → «Доброго утра», «Чем помочь этим $V?» → «Чем помочь этим утром?». Без `|` `$V`
совпадает с `$T`. Утро — до 12 часов, день — до 18, дальше вечер.

## Перевод в «Системе Переводчик»

Проект Ultima VI в СП (https://translate.old-games.ru, проект 71) — диалоги (перевод «Ultima VI Scripts») и
графика. Что где правится:

| Что | Где |
|---|---|
| Реплики диалогов (`'russian'` у пар `{'english': …, 'russian': …}` в `conversations/*.txt`) | СП |
| Перерисованная графика (`graphics/`) | СП |
| Ключевые слова (`case {'russian': …}`), сценарии, `[russian]`-блоки | git |
| Тексты EXE (`patches/translation.json`), осмотр (`unpacked/look.json`), книги (`unpacked/book.json`) | git |

Реплики в СП хранятся как в файле сценария: `\n` — новая строка, `\'` — апостроф, `\\` — обратная косая черта
(формы числа `/` и `\\`). Перед репликами каждого файла — служебная строка с именем файла и пустым переводом.
Реплики диалогов в git руками не править — следующий перенос из СП их перезапишет.

Перенести переводы из выгрузки СП (ZIP проекта или распакованная папка) в репозиторий:

```
python3 -m tools.sp import project.zip [--dry-run] [--report отчёт.md]
```

Меняется только текст в `'russian': '…'` и `graphics/` (как `tools.shapes import`). Реплики сопоставляются по
ключам (колонка C в СП), в выгрузке без ключей — по служебным строкам и порядку. Английский текст сверяется со
сценарием: если не совпал (в git правили сценарий, а в СП — нет), файл или реплика не меняется и попадает в отчёт.
Не применяются и переводы, которые игра не выведет: символы не из CP866 (`«»`, `—`, `…`), `\` в конце строки.
Код выхода 2 — есть неприменённые фразы, отчёт со ссылками на фразы в СП.

Автоматически это делает workflow «Sync from SP» (`.github/workflows/sp-sync.yml`): раз в сутки (если перевод в СП
изменился), на push в master и вручную (Actions → Sync from SP → Run workflow). Он переносит перевод, прогоняет тесты,
собирает игру и заливает её на файловый сервер в папку сборок проекта (`buildsDir` в настройках СП) как
`Ultima6_build_<месяц><год>.zip` (в течение месяца перезаписывается, остаётся последняя сборка месяца), а правки
`conversations/` и `graphics/` выкладывает в ветку `sp-sync` с PR в master. Отчёт — на странице запуска и в PR.

Новая реплика в сценарии (git) в СП сама не появится: отчёт пишет «реплики нет в СП» с ключом — админ добавляет
фразу с этим ключом вручную. Ключи к выгрузке без ключей: `python3 -m tools.sp keys project.zip keys.xlsx`, затем
в СП «Обновить из файла» (по порядку) — сразу после выгрузки, иначе правки, сделанные в СП между выгрузкой и
обновлением, сотрутся.

## Графика: заставка, меню, создание персонажа

Перерисованные кадры лежат в `graphics/` как PNG: `graphics/MAINMENU.SHP/000.png` — кадр 0 архива `MAINMENU.SHP`.
Сборка (`tools.build`, русские данные) собирает из них архивы `*.SHP`; кадры без PNG остаются оригинальными.
PNG — indexed с палитрой игры, прозрачный цвет — индекс 255 (подробности в `tools/shapes.py`).

Перерисовки ведутся в «Системе Переводчик». Обновить `graphics/` из выгрузки СП (ZIP проекта или распакованная
папка) — `python3 -m tools.shapes import project.zip` (или `tools.sp import` вместе с диалогами): в `graphics/`
попадают только кадры, отличающиеся от оригинала. Оригиналы кадров с текстом для загрузки в СП — `python3 -m tools.shapes export original <папка>`.

## Шрифты

Шрифты игры хранятся текстом: `tools/U6.CH.txt` (основной, 8×8) и `tools/U6.SET.txt` (пропорциональный: заставка,
создание персонажа); сборка делает из них `U6.CH` и `U6.SET`. Раскладка — CP866.

Для банка шрифтов СП — BDF: `python3 -m tools.bdf export tools/U6.CH.txt U6_CH.bdf Ultima6-U6.CH`. Поправленный
в СП шрифт (скачать BDF из карточки шрифта) — обратно: `python3 -m tools.bdf import U6_CH.bdf tools/U6.CH.txt`.
Импорт меняет только знаки 0x20–0xFF, которые есть в BDF; символы вне CP866 пропускает с предупреждением, знак
неверной ширины или выходящий за 8 строк — ошибка.

## Сборка: установленная игра

`python3 -m tools.build` кладёт в архив уже установленную игру — то, что делает `INSTALL.EXE` (жёсткий диск,
VGA/MCGA, мышь, AdLib 388): карту `MAP`, начальное сохранение `SAVEGAME/` с русскими именами спутников,
`CONFIG.U6` (`tools/install.py`, сверено с `INSTALL.EXE` байт в байт). Без установки `MAP` в дистрибутиве пустой и
игра стоит посреди воды. Сборка тестовая, для переводчиков: Аватар уже создан (мужчина, имя «Аватар»), сразу «К
приключениям». Запуск русской версии — `U6RUS.BAT` (клавиатурный драйвер `UNIKBD` с русской раскладкой, затем
`ULTIMA6.EXE`; просто `ULTIMA6` запустит `ULTIMA6.EXE` без драйвера).
